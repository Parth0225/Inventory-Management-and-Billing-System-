# Inventory & Billing Management System

A Python-based Inventory and Billing Management System designed to manage
products, inventory, customers, suppliers, sales, billing, and reports.

## Features

- User Login
- Product Management
- Inventory Management
- Customer Management
- Supplier Management
- Billing System
- Sales History
- Stock Management
- PDF Bill/Receipt Generation
- Database Integration
- Reports

## Technologies Used

- Python
- OOP
- SQL / MySQL
- Tkinter / CustomTkinter
- Git & GitHub
- ReportLab

## How to Run

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Configure the database.
5. Run the main Python file.
